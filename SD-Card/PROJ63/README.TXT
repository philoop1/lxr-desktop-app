PROJ63 is a kit library for Mutador 0.2.12. Slots 00..60 contain the LXR2 kits converted from P000..P060.PRF. To import one into the current project: stop the sequencer, LOAD + Step 7, select PROJ63, press KIT, choose source slot, choose destination slot, confirm. A filled destination asks for a separate Replace confirmation. Do not load PROJ63 as a full project; it has kits only. Original LXR1 SND files are in F:\LXR1\SOUNDS\LXR1.
