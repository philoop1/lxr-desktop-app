# 5. MIDI and clock

The desktop firmware includes DIN and USB MIDI handling. The menus expose
per-voice MIDI channel and note settings, plus global MIDI channel, MIDI
filtering, routing, BPM, shuffle and clock settings. The exact behavior of
each routing and synchronization option should be checked on hardware before
it is described as a procedure here.

MIDI-delay experiments from LXR2BC or mutador have **not yet been ported** to
this desktop firmware. Once a feature is ported, this chapter should state
its range, interaction with clock sync and test result.
